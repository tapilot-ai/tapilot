# 语音润色

参考 `../studio/packages/mobile-speech-input/src` 的 `speechPolish.ts`、`speechPolishPrompts.ts`、`SpeechPolishPreview.ts` 和 `SpeechPolishSettingsSection.tsx`，以 Kotlin 实现。

## 使用

设置页新增“语音润色”。默认关闭，独立填写 OpenAI 兼容的 HTTPS Base URL、模型和 API Key，自动保存。可展开编辑中文和英文提示词、恢复默认提示词及删除润色密钥。密钥由现有 Android Keystore 凭据存储加密，不与火山引擎 / Deepgram 转写密钥或对话模型配置混用。

默认中文、英文提示词与 Vibelet 当前版本一致：去除无意义口癖、合并无意重复、保留明确的最终自我纠正，谨慎校正近音误识别，保留事实、数字、否定、专有名词和语气；明确列举时生成编号列表，按语义自然分段，不回答或执行转写中的指令。

聊天输入、全局助手和兼容语音桥均经过同一个润色包装器。录音停顿 800 ms 后预览润色；连续说话最长约 3 秒触发一次，请求间隔至少 3 秒，并串行合并更新。原转写被识别服务修正后不会复用不匹配的润色前缀。松手后先等待完整转写，再处理完整文字，避免遗漏尾字。每次润色请求最多 5 秒，失败、空结果或缺少密钥时保留原转写。取消会中止请求和队列，迟到结果不会回填或发送。切换对话会取消正在处理的语音。回填沿用 Vibelet 的换行追加规则，保留分段和列表。

## 验证范围

- 正常 APK 和独立 `speechverify` APK 构建通过。
- 116 项原生测试通过，其中新增 11 项（含需显式启用的真实服务测试），覆盖协议请求、失败回退、语言提示词、配置校验、尾字、前文识别修正、取消、重复提交和换行追加。
- 独立 Android 35 ARM64 模拟器 `emulator-5584`，使用 Midscene 操作实际原生界面：聊天润色回填、503 回退原文、全局助手润色回填及取消后的迟到回调验证通过。验证 APK 使用合成转写和确定的 API 响应，执行实际生产润色客户端和 UI；没有使用真实录音或真实润色服务，不把模拟器结果作为真机验收。
- 最终正式 APK 的设置页通过 Midscene 填写合成测试地址、模型及密钥，自动保存通过；核对 SharedPreferences 的配置值及密钥密文，未输出密文或密钥。强制退出并重启后，保存的配置和密钥仍保留。默认中英文提示词另经脚本逐字核对，与 Vibelet 相同。
- 无效 HTTP 地址不会覆盖已保存的有效 API 配置。在该编辑状态下关闭润色后，核对持久配置 `enabled=false`，原密钥保留；验证截图仍显示无效地址提示，但关闭已经生效。
- 取消前允许有预览请求。`cancellation.json` 核对最后预览请求时间早于取消完成时间；迟到的最终回调没有回填、发送或生成新的润色请求。
- 初次独立验证包安装被 MIUI 拦截并要求小米账号本人认证。后续继续时，正式 APK 两次覆盖安装均返回 Success，真机设置页已核验；独立验证包仍未安装。未修改 Mac 网络。

截图和产物信息位于 `docs/visual-baseline/20261007-speech-polish`。正式 APK 不包含合成转写、API 响应或验证 Activity。

## 后续真实服务与真机验证

真实服务使用本机已有的测试模型配置，只发送合成测试句子。初次 Kotlin 客户端请求在 5 秒超时后回退原文。排查发现 Qwen 3.7 Plus 默认开启思考；依据[阿里云官方文档](https://www.alibabacloud.com/help/zh/model-studio/deep-thinking)，仅对阿里云官方接口上的 Qwen 3.5 / 3.6 / 3.7 Plus、Flash（含日期快照）设置 `enable_thinking=false`，不对仅支持思考的 Max 或任意第三方兼容接口发送该参数。DeepSeek 和 Gemini 的原兼容处理保留。

修正后重新构建正式 APK，并执行全部 116 项测试，包括真实 Kotlin `SpeechPolisher` 请求。HTTP 200，耗时 1904 ms，使用默认中文提示词，得到：

> 1. 检查登录
> 2. 测试录音
> 3. 更新文档
>
> 明天不要发布。

结果保留编号、事实和否定。详细回执见 `live-service.json`。这是真实服务协议验证，不能代替手机录音链路。

修正后的正式 APK 已覆盖安装到 Redmi K30 Ultra。通过 Midscene 设置页临时配置测试润色 API，核对 Android Keystore 密钥已保存，再通过 Midscene 长按输入区，尝试录制 Mac 播放的合成普通话测试音频。火山引擎在产生转写之前返回 HTTP 403，提示当前 Key 没有 `volc.seedasr.sauc.duration` 的资源权限；该资源与 `../doubao-say` 当前设置一致。输入框没有回填，历史仍为 43 项，历史哈希前后相同。录音、转写、润色到回填的真机完整链路尚未通过，需要为该 Key 开通 Seed ASR 2.0 小时版，或换用已有权限的 Key。Deepgram 未做本轮真机转写验证。

临时润色密钥填写时关闭 Midscene 报告、执行记录和缓存，并脱敏标准输出；诊断文件的普通写入路径拒绝包含该密钥的内容；最终审计发现 SDK 的流式底层诊断日志未经过该保护，已对 4 个本地日志脱敏，补上流式写入保护，并再次检查无密钥明文匹配。测试后清理该临时润色密钥并关闭自动润色，保留原火山转写密钥、对话模型配置和历史。最终清理结果见 `device-check.json`。
