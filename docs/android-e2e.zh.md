# Tapilot Android 真机回归

每次发布前在已解锁的真机上运行。保留每项的屏幕截图和 Tapilot 报告；只把实际观察到的结果标为通过。测试用语音和图片不含私人内容。

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 语音输入 | 分别选择火山引擎和 Deepgram，按住说一句中文，松手 | 转写进入草稿；失败时可重试，草稿不丢失 |
| 屏幕问答 | 从其他应用点悬浮球，问当前屏幕上的可见文字 | 回复与原页面一致，返回后仍在原应用 |
| 分享图片 | 从相册经系统分享面板选 Tapilot，再问图片主体 | 输入区出现图片附件；助手能依据图片回答 |
| 取消操作 | 开启“每步确认”，请求打开设置，在确认框点击取消 | 不执行手机操作；聊天记录显示停止或失败，不显示完成 |
| 验证成功 | 请求打开设置首页，并确认搜索框可见 | 报告包含成功的 `aiAct` 和 `aiAssert`；聊天说明所见结果 |
| 验证失败 | 在高级模式运行先打开设置、再断言桌面可见的 YAML | `aiAssert` 失败；界面和报告均不显示任务成功 |
| 全局入口 | 在非 Tapilot 应用点击悬浮球，再输入问题 | 底部面板显示在原应用上方；键盘不遮挡输入和发送 |

真机操作应使用设备锁。构建通过 `dev-gate run --kind heavy` 执行，安装前等待构建退出。模拟器可补充普通界面回归，不能代替语音硬件和真机安装验收。

当前已实测：小米 MIUI 14 真机上的图片分享与问答、悬浮球、文字分享、逐步确认、设置首页操作及最终画面断言。火山引擎已用合成语音通过服务端转写；手机麦克风的语音转写、Deepgram 真机转写仍待完成。
