# Vibelet 经典主题对齐

2026 年 10 月 5 日。参考 `../studio/apps/vibelet-app/services/theme.ts` 所使用的 `../studio/packages/mobile-theme/src/classic.ts`，以 Vibelet 默认的 `classic` 主题为基准；没有改用可选的 `minimal` 配色。

## 对齐范围

- 浅色背景 `#F4EFE7`，卡片 `#FFFDF9`，标题栏 `#FBF8F2`，主色 `#A87BB2`。
- 深色背景 `#161C22`，卡片 `#222A33`，标题栏 `#1C232B`，主色 `#B272C0`。
- 用户消息为紫色与白字，助手消息使用暖白 / 灰蓝底色；气泡圆角 20 dp，尾角 8 dp，用户最大宽度 82%，助手最大宽度 92%。
- 设置卡片圆角 24 dp、细边框；输入和按钮圆角 18 dp。设置背景使用经典主题的淡紫与淡粉圆形装饰。
- 聊天、设置、高级编辑与全局录音使用同一个原生主题。状态栏和标题栏同色通顶，报告页面与全局面板同步使用主题颜色。
- 继续保留微信式长按录音的布局、上滑后松开取消和发送区域；本轮调整其主题颜色，没有重写转写协议或对话 Agent。

配色维护在 `theme/brand.json`，由 `scripts/generate-brand.mjs` 生成 Kotlin、Android XML 和报告 CSS。半透明边框及装饰颜色在 CSS 中使用 RGBA 十六进制，在 Android 中转换为 ARGB。

## 验证

通过受管 Gradle 构建及主题生成一致性检查，安装到 Xiaomi M2006J10C / MIUI 14。使用 Midscene 基于截图切换主题、查看设置与已有报告；没有发送模型任务或修改 API 配置。

本轮开始时工作区已有录音动效改动，已保留。安装包包含当前工作区的这些改动，本轮没有将它们回滚。

六张截图均来自最后一次安装的 APK，覆盖浅色聊天、键盘、设置，以及深色聊天、设置、报告。设备安装包经流式 SHA-256 核验与本地构建相同；见 `manifest.json`。

`verification.json` 确认密钥文件未变、历史完整保留、未发送新消息，当前会话、草稿和跟随系统主题均已恢复。报告回放中的蓝色浮层属于此前录制的视频内容，不代表当前应用的控件颜色。没有重新验收真实语音转写或组合任务完成能力。
