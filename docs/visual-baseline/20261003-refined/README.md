2026 年 10 月 3 日。本轮样式实现见提交 `fd1f142`；[截图总览](index.html) 是本次实际采集的页面，旧目录保留历史验收记录。

## 本次调整

- 保留 Midscene 的蓝紫品牌色，将主要操作集中在蓝色按钮，页面背景与输入框采用中性色。普通消息去掉渐变，助手回复直接排在页面上。
- 聊天标题、正文和次要文字分级，缩小装饰、减少圆角与阴影，增加消息之间的留白。空白对话移除大图标和自我介绍。
- 输入框、语音切换、附件和发送按钮的区域为 48 dp。可发送时使用实心蓝色，空草稿时显示禁用状态。
- 设置图标采用灰色线条，配置分组使用较小圆角。主题选项去掉彩色底块；说明文字统一使用随主题切换的次要文字色。
- 报告切换标签采用纯色分段样式，原生工具栏去掉投影。全局助手的发送按钮与任务状态提示也统一使用纯色。
- 聊天、设置、报告标题栏继续与状态栏通顶，内容位于安全区内。

本次变更涉及共享主题和页面呈现。`ChatController`、`HoldToRecordEditor`、`RecordingFeedback`、语音协议及任务执行代码没有修改，微信式录音布局和持续手势沿用已有实现。
