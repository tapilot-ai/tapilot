# Vibelet 主题配置对齐验收

2026-10-05，小米 M2006J10C / Android 12 / MIUI 14 真机验收，通过 Midscene 操作。七张截图来自本轮修复后的同一个 APK，具体产物哈希见 manifest.json。

## 配置

- 主题与明暗模式分别保存：经典 / 素雅；跟随系统 / 浅色 / 深色。默认经典、跟随系统；旧配置没有主题字段时保留原明暗模式，未知主题回退经典。
- 主题选择器沿用 Vibelet 的双卡片、四个浅深色预览色块、选中标记及说明文案。
- Compose、原生 Android 控件、状态栏、悬浮球、全局助手和 HTML 报告共用 theme/brand.json 中的配色。
- 素雅主题没有背景装饰，使用蓝色控件、淡蓝用户气泡及独立气泡文字颜色。深色按钮文字和气泡文字使用不同颜色，避免套用同一前景色。
- 保存按钮保留上轮的紧凑尺寸；微信录音交互保留原实现。

参考源：studio/packages/mobile-theme/src 下的 classic.ts、palettes.ts、store.ts、ThemePicker.tsx。

## 实测

- 经典、素雅主题切换，主题选项即时更新；主题切换不重置明暗模式。
- 素雅浅色、深色设置页，经典深色及跟随系统设置页；标题栏与状态栏配色一致。
- 素雅浅色退出主页面再打开，配置保留；修复版覆盖安装再启动后，素雅深色配置仍保留。
- 素雅深色聊天、报告回放、悬浮球与全局助手面板显示正确。本轮没有发送消息、点击重试或调用模型 / 转写 API。
- 初次测试发现设置页切换深色时只刷新设置值；已改为在主题组合的外层读取明暗模式状态，重新构建、安装并验证浅深色即时刷新。

报告截图中的旧蓝色“正在处理”浮层属于历史录屏内容，当前回放页使用新主题。聊天截图中的 HTTP 400 为已有消息，本轮没有发起模型请求。
