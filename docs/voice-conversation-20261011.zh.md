# 连续语音对话（2026-10-11 验证记录）

本记录对应首轮实现。后续跨应用对答、指令收到反馈和普通回答朗读见
[全局语音对答](voice-conversation-20261012.zh.md)。以下前后台暂停规则已在后续版本替换。

## 功能

在空输入框右侧点击声波图标开始，保留原有长按录音交互。停顿约 1.2 秒后
结束当前录音并发送转写结果；当前 Pi 对话 Agent 处理这一轮，回答或追问通过
API 播报，播放结束后继续监听。对话上下文由现有 Agent 维护，Midscene 仍只
执行当前具体手机指令。

底部面板显示监听、转写、处理、播报、暂停和错误状态。点击打断可以立即
停止播放并开始下一轮录音；暂停、结束、返回以及会话切换都会停止音频。
30 秒没有说话会暂停监听。前台离开时暂停麦克风和播报，回到前台后根据
任务状态继续；用户主动暂停的会话不会自动恢复。手机操作确认仍由用户点击
执行或取消，语音模式不会自动批准。

## 接入

- 火山引擎：沿用 Seed ASR 2.0 小时版，播报使用 Seed TTS 2.0 单向流式 HTTP。
  默认音色 `zh_female_vv_uranus_bigtts`，与 Studio ai-core 一致。
- Deepgram：Nova-3 转写，Aura-2 播报，默认音色 `aura-2-thalia-en` 为英文。
- 默认复用当前转写服务密钥，可在设置页单独保存播报密钥和音色，并试听。
  密钥使用现有 Android Keystore 加密存储；输入、播报均不使用系统语音服务。
- 播报使用流式 AudioTrack，逐块处理 PCM。网络块可能在采样的两个字节之间
  截断，播放器保留末字节并与下一块合并，等最后一帧播放完成才恢复录音。
- 转写和播报权限分别开通。测试手机现有火山密钥已实际完成两类 API 请求。

接口依据：
[火山引擎单向流式 TTS](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)、
[Deepgram Speak API](https://developers.deepgram.com/reference/text-to-speech/speak-request?explorer=true)。

## 验证与边界

本轮 152 项 Kotlin 单元测试通过，其中 15 项覆盖连续对话、旧回复去重、
取消后回调隔离、前后台切换、手动暂停、重试、确认流程、低音量停顿、长句保护和 PCM
分片边界。原生 APK 构建通过，已覆盖安装到 Redmi K30 Ultra。

真机测试使用 Mac 播放两段合成普通话，由测试手机真实麦克风采集，经过
火山引擎转写、百炼订阅模型回答和火山引擎播报。先让助手询问喜欢的颜色，
再回答紫色，核对回答保留上下文，音频确实进入 AudioTrack 并播放到最后一帧，
每轮之后恢复监听。证据在 `artifacts/20261011-voice-conversation/`。

早期测试遇到空闲后模型请求超时，并收到一段非测试样本的环境语音；相关测试
任务已停止，记录保留。模型传输现在为每轮请求设置 `Connection: close`，
避免空闲 HTTP 连接影响续聊。后续测试在新对话中紧接着播放两段样本，并在结束后
立即关闭监听。播报日志核对使用每轮任务的时间戳，避免日志缓冲刷新导致
完成事件累计次数误判。

当前采用轮流监听与播报，打断通过点击按钮完成；尚未实现说话直接打断、
唤醒词和锁屏后台持续监听。Deepgram 的真机链路未在本轮验证。API 超时和
网络波动仍可能影响响应；任务失败会保留记录，可点击任务重试。
