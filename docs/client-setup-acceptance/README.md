## 真正的新用户验收步骤

1. 用户在系统设置创建并登录一个标准测试账户，密码由用户自行设置。保留原用户登录和现有会话。
2. 从共享目录解压安装包并双击 `Install Tapilot.command`。
3. 客户端本身需单独安装和正常登录；Tapilot 接入包不包含第三方客户端。不得复制旧用户配置或凭据来跳过首次接入。
4. 分别完成豆包工作连接器和 Skill 导入、WorkBuddy 启用、DSH Web 原生插件注册。
5. 在真实会话内打开侧栏，确认实际手机像素，执行获授权的只读任务并记录结果。
6. 验证客户端退出重启、历史会话重开、升级和断线恢复；遇到手机占用或隐私暂停，保留现场，不自动抢占或恢复。
7. 代理需要在测试账户中重新打开 Codex 并接续验收；当前账户内的代理不能替代新用户登录或输入系统密码。

Cursor 按用户要求排除。DSH Web 和 DSH Go 分开记录。本轮未测试 DSH Go，也未公开发布安装包。
