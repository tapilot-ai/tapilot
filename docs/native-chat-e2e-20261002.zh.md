# 原生聊天迁移与真机验收（2026-10-02）

## 实现范围

聊天页、会话列表、消息气泡、附件入口、操作确认和输入区迁移到 Kotlin + Jetpack Compose。文字输入使用 Android EditText，支持键盘发送、多行草稿及长按录音。原生录音直接使用已有 SpeechTranscriber 和 Keystore 中保存的 API 密钥。

文字框长按后显示录音浮层；上滑只进入“松开取消”状态，移回可继续录音，松手才取消。文字模式松手转写到草稿；语音模式松手转写后发送。切后台会取消录音，并丢弃已取消请求的迟到结果。

现有对话 Agent 继续拥有上下文和任务规划，Midscene 继续执行设备操作。Agent 暂由隐藏 WebView 运行，通过版本化状态与命令接口连接原生界面；设置、高级 YAML 编辑、HTML 报告仍使用 WebView。此次不是整个运行时迁移到 Kotlin。

## 真机观察

设备：小米 M2006J10C，MIUI 14。使用 Android 设备锁串行操作，Midscene 按截图执行并生成报告。

| 场景 | 结果与范围 |
| --- | --- |
| 历史兼容 | 原聊天历史和模型配置保留；原生会话列表可切换，新会话可创建 |
| 键盘避让 | 键盘弹起后输入框和发送按钮完整可见，Midscene 断言通过 |
| 按钮发送 | 草稿进入用户消息，输入框清空；模型响应为欠费错误 |
| 键盘发送 | 点击输入法“发送”，草稿进入消息并清空；模型响应为欠费错误 |
| 录音取消 | 连续手势中上滑显示红色“松开取消”，移回恢复蓝色；上滑后松手取消，不改变草稿或附件 |
| 火山引擎实际转写 | Mac 播放中文测试音，手机麦克风录音；实际 API 返回“这是原声语音输入测试。”并进入草稿。原测试音为“这是原生语音输入测试”，存在同音字差异 |
| 草稿恢复 | 已转写草稿在覆盖安装和重新启动后保留 |
| 附件 | 原生菜单显示照片、拍摄、文件；通过系统选择器选取真实 PDF，原生显示文件名和预览，再移除。未发送给模型；另已打开系统相机和照片选择器并取消返回，未实际拍照或选择私人照片 |
| 设置互通 | 原生入口打开设置；语音服务检查后恢复火山引擎；单次系统返回由独立断言验证 |
| Deepgram | 设置页显示尚未配置 API Key；本次未进行真实转写 |
| 完整任务执行 | 未通过：手机当前对话模型返回 HTTP 400 / Arrearage，不能验证成功回复及设备任务执行。主界面还提示需开启设备控制；未把旧版任务验收当成本次通过证据 |
