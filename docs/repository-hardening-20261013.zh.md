# 仓库审查修复记录

本次修复基于 ebc4797，不改变闭源许可，也不改变现有语音浮层的配色、按钮位置和松手规则。

## 修复范围

1. 对外开放的 MainActivity 不再读取 Intent 中的 START_VOICE。录音只由用户交互、内部 VoiceEntryActivity 或本次麦克风授权回调启动。
2. Node 事件解析或监听器失败时，先终止并等待子进程退出，再释放所有权。终止失败时保留进程引用，阻止新任务覆盖旧进程。
3. 增加不可调试的 Beta 变体，沿用现有安装证书；正式 Release 必须提供 TAPILOT_SIGNING_*，产物脚本核对包名、版本、签名和 debuggable 状态。Beta 兼容证书仍不是生产签名；正式证书迁移需要另行安排。
4. ConversationWriter 在专用线程序列化、写入和 fsync。主线程仅捕获独立快照；后续外部操作等待持久化完成。草稿写独立文件，使用基础版本标识防止旧草稿覆盖新任务状态。
5. Node 资源清单保存源码指纹和 ZIP SHA-256。Gradle 打包前验证两者，存在但过期的资源无法出包。生成资源时强制重建适配器。
6. 密钥按服务商读取。界面仅检查是否存在；损坏记录不影响其他服务商，读取失败提示重新填写或重置。转写新增单项清除入口，播报和润色的清除入口在记录损坏时仍可使用。
7. 上下文投影限制请求大小，缩短执行日志，保留系统与用户约束、工具参数和完整工具配对。约束本身过大时明确停止并保留记录；不默默删掉要求。图片采用单独视觉预算，另设传输大小上限。
8. FloatingVoiceSession 统一持有悬浮语音状态，Activity 和悬浮球通过操作方法推进状态。取消、重试和新会话使旧代次失效，迟到的麦克风与截图回调不得发送旧内容。
9. pnpm check / pnpm test 串行覆盖类型、旧界面、适配器、Node、脚本、Kotlin、Beta 构建和 APK 核验。本机自动使用 dev-gate；未启用付费远程 CI。
