# 状态栏与标题栏真机实测（2026-10-02）

验证版本：`8c6a0dd`。设备：小米 M2006J10C / MIUI 14，当前浅色主题。使用设备锁及 Midscene 操作；未修改模型、语音密钥或系统网络配置，未输入或发送测试消息。

## 结果

- 首页：系统状态栏与 Tapilot 标题、副标题区域均为白色，无独立浅蓝色状态栏色块。标题和按钮未被遮挡。
- 键盘弹起：输入框位于键盘上方，顶部布局保持完整。
- 设置返回：进入设置后只按一次系统返回，回到原生聊天页；独立视觉断言通过，顶部背景保持连续。

首次颜色视觉断言失败，模型把标题栏判断为浅蓝色。随后检查原始 PNG 的背景像素：1080 × 2400 截图中 `(500,30)`、`(500,90)`、`(500,180)`、`(500,240)` 均为 RGB `(255,255,255)`；聊天内容区 `(500,280)` 为 `(245,248,255)`。结合截图人工查看，颜色差异来自下方聊天内容区。设置返回后的独立断言明确区分标题区和聊天内容区，通过。

键盘断言通过，但人工检查发现 MIUI 系统悬浮气泡盖住发送图标。已通过 Midscene 将气泡移到右侧中间靠上位置，并再次弹起键盘留图。这是系统浮窗遮挡；本次未修改应用代码或关闭浮窗。
