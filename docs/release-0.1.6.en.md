# Tapilot 0.1.6 Beta

- Receive an immediate acknowledgement when your instruction is accepted.
- Keep a voice conversation going while using other apps, with spoken answers and follow-up questions.
- Pause, resume, interrupt or end voice conversations from the notification.
- Hear new assistant answers in regular text chats, or read an individual answer aloud. Automatic playback can be disabled in Settings.
- Keep the input placeholder vertically centered.

Configure your own Volcengine or Deepgram speech credentials. Voice playback uses the selected provider API; credentials are not included in the APK. Interruption currently uses a button; wake words and spoken interruption are not supported.

Android 11+, ARM64. This beta uses the existing debug signing certificate.
