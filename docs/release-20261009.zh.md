# Tapilot 0.1.2 测试版发布

版本 0.1.2 / versionCode 3；Android 11+ / ARM64，继续使用与已安装测试版兼容的 Android Debug 签名，不是应用商店正式版。

本轮包括 Remosidian 风格输入框、锚定会话下拉菜单、附件菜单、三种执行模式，以及设置页检查更新和飞书下载跳转。已有验收见 docs/acceptance/20261009-app-update.md 与 20261009-execution-mode.md。

发布顺序：固定源码 → 构建和校验签名 → 真机覆盖安装 → 飞书上传、公开下载校验 → 更新 studio 官网清单 → Git 自动部署 → 手机检查更新验收。未完成阶段不记为成功。

语音识别和润色保持已有实现，本轮不声称火山引擎与 Deepgram 转写完成新增真机验收。API Key、聊天内容和设备配置不进入分发包或公开发布说明。
