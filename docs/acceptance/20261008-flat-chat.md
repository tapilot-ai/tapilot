# 会话下拉与输入区精简验收

参考 Vibelet 的 ChatComposerDock 和 mobile-chat-ui 控件布局；按本轮要求，Tapilot 使用无底色按钮，并进一步减少常驻控件。

## 改动

- 右上角会话入口改为锚定图标的悬浮下拉菜单，没有模态遮罩；新对话与高级 YAML 入口收进菜单。
- 底部只常驻附件加号和文字框，有草稿或附件时显示无底色发送箭头，任务执行时保留停止入口。移除独立语音切换按钮与输入框边框。
- 附件入口也使用小型悬浮菜单，保留照片、拍摄、文件。
- 空输入框收起键盘时清除编辑焦点，恢复“长按语音输入”；长按录音手势与反馈组件保留。
- 将输入区与下拉菜单拆成独立 Kotlin 文件。

## 验证

Gradle assembleDebug 构建成功。Redmi K30 Ultra（s4ey59ytbitot4yp）已通过 adb install -r 覆盖安装，保留原数据；使用 device-android 会话锁，以截图观察及基于截图的 ADB 输入实测。

已检查右上角会话下拉、新对话、附件菜单、输入文字、键盘避让和空草稿按钮隐藏。测试草稿 Layout test 已清除，没有发送消息或触发模型任务。本轮不声明模型回复、语音转写或拍摄上传完整链路通过。
