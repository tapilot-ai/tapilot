# 对话 Agent 操作预算修复

## 改动

原生 Agent 单任务手机工具调用上限由 4 提高到 100，对话模型轮次由 8 提高到 101，最后一轮允许汇总。一次工具调用是整段 Midscene 指令，不是单次点击。100 次仅作为异常循环保护；停止按钮仍在模型返回前后和每个工具执行前后检查。旧网页 Agent 源码同步上限，原生 APK 使用 Kotlin Agent。
