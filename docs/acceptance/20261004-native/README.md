# 设置与对话逻辑原生迁移

2026 年 10 月 4 日。聊天、设置页和高级 YAML 编辑均由 Kotlin / Compose 呈现。原生对话 Agent 管理会话上下文、附件、重试、编辑重发、操作确认、停止和全局请求队列；Midscene 保留设备内 Node.js 引擎，执行报告保留独立 HTML WebView。

## 数据兼容

首次升级创建一个临时 WebView，只读取旧来源的本地存储，不加载旧对话运行时。模型参数、草稿、会话及附件引用导入私有原生文件，提交成功后销毁临时 WebView。后续启动直接读取原生文件；普通 APK 不包含旧网页资源。旧 WebView 数据保留，便于恢复。

API Key 继续使用原有 Android Keystore 和加密偏好文件。导入不覆盖已存在的加密凭据，也不会把 Key 放进原生会话文件。旧记录里的运行中任务改为停止，避免重启后显示虚假的进行中状态。

私有会话文件原子替换，损坏时提示错误，不静默清空。原生历史上限扩大为 200 条；上下文只读取当前会话，历史附件最多载入最近两条成功消息。附件私有副本随历史清理。

## 真实服务问题

真机原模型配置的实际请求返回 HTTP 400，脱敏诊断明确为 `Arrearage`（欠费或余额不足），并非模型名称错误。原生界面现已单独说明这一原因。[阿里云官方错误码说明](https://help.aliyun.com/zh/model-studio/error-code)也将该代码解释为账户欠费。

测试临时使用本机已有的可用模型配置，不充值、不修改网络服务。火山引擎此前的资源授权 403 仍未解除，不能将本次界面迁移验收作为真实语音转写成功的证据。

Android debug APK 构建和 98 个原生单测通过。新增测试覆盖旧存储导入、附件与报告引用保留、原子保存、损坏保护、模型请求、欠费提示、上下文组装、停止后的工具调用阻断及操作次数限制。普通 APK 的资源检查确认没有 `assets/index.html` 或旧网页脚本。

## 真机记录

设备：Xiaomi M2006J10C，MIUI 14。

迁移前记录 20 条历史、当前会话、模型配置及加密凭据文件哈希；首次导入后只读核验确认记录全部保留，凭据哈希一致。

初版测试仍沿用 20 条历史上限，第一条新消息淘汰了一条旧记录。发现后已从本轮备份恢复该条记录并扩大保留上限；不以首次导入成功掩盖这一修复过程。

## 已完成的交互验收

使用 Midscene 基于真机截图操作界面，并读取应用私有状态核验结果；未用模拟回复代替真实模型请求。

- 普通对话：发送 `3+4`，真实回复 `7`。
- 文件与上下文：从系统文件选择器发送验收文件，回复 `TP-NATIVE-1047`；下一轮不重新附文件，仍回复项目名称“松果”。
- 附件预览、编辑重发与重试：长按原文件消息编辑后重发，随后重试最新文本消息，两次均回复“松果”；私有状态确认沿用同一附件引用。
- 会话隔离：新建会话再询问旧文件，模型说明本对话没有提供文件，没有串入旧上下文。
- 停止：长回复请求发送后点击停止，界面及私有状态均为 `stopped`；操作确认中取消也进入停止状态。
- 手机操作：对话 Agent 调用 Midscene 打开计算器，完成 `2+3=5` 的最终画面断言并返回聊天，保留 Agent 报告和 Test Runner 汇总。
- 报告入口：发现移除旧网页资源时遗漏了报告导出脚本，导致报告页退出。修复为独立打包 `public/` 中的报告资源；重新安装后报告步骤页正常打开。构建增加 APK 内容检查，确认报告资源存在、旧网页资源缺席。
- 全局入口：发现全局面板曾创建第二个聊天 Activity。主入口改为 `singleTask`，全局面板显式返回主任务；修复后系统只读检查确认只有一个主入口实例。

## 模型行为限制

“先计算，再只回复旧文件项目名称”的组合指令在测试模型 `qwen3.7-plus` 上跳过了计算步骤，直接回复“松果”。私有状态没有执行报告，屏幕仍显示旧结果 `5`，因此这项不算手机操作成功。加强 Agent 提示后该用例仍未通过；单靠提示词不能保证多项要求都被执行，后续需要行动计划及完成检查。

本轮未修改微信录音输入组件，也未重新验收真实语音转写。此前火山引擎资源授权问题仍需单独处理。

最终包的全局手机操作采用明确的单项请求：实际清空计算器、输入 `3+4`、点击等于号、断言屏幕显示 `7`。私有状态为成功，并包含 Agent 报告与 Test Runner 汇总。结果浮层仍在计算器上；点击“查看对话”回到同一个会话，最新回复和报告均可见。全局回复项目名称的独立路径也能沿用原会话的文件上下文。这些结果不能替代上面未通过的组合指令验收。

设备内已安装 APK 经流式 SHA-256 核验，与本轮最终构建产物一致。
