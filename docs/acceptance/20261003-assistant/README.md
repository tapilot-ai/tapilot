# 助手功能与真机验收

2026 年 10 月 3 日。本轮沿用 `fd1f142` 的精简样式和 Midscene 品牌色，扩展语音检查、任务进度、消息操作和全局助手。聊天继续由 Kotlin / Compose 呈现，对话 Agent 管理上下文，Midscene 接收具体操作指令和可观察的成功条件。

## 实现

- 语音设置增加“检查语音连接”：使用 Android Keystore 中已保存的 Key 实际连接服务，不打开麦克风。火山引擎发送 Seed ASR 初始化请求并检查应答，Deepgram 检查 WebSocket 鉴权。资源未授权、鉴权失败、额度不足和限流分别给出提示；错误不会直接复制服务响应中的敏感内容。关闭控制器时取消连接检查。
- 执行中显示任务阶段、操作指令、当前屏幕操作、用时和停止入口。停止会取消模型请求及设备执行，且阻止迟到的模型响应继续调用工具。完成后展示回复，手机执行记录按需打开。
- 回复支持复制和重试；用户消息长按可复制或编辑后重发。重发保留原附件，成功任务重新执行前有确认提示。文件和图片可预览，PDF 展示已转换的页面。
- 附件副本保存在应用私有目录，历史只保存引用。重启后可打开、编辑或重试；无引用的副本随历史清理。Agent 加载当前会话最近两条成功消息的附件，限制历史图片数量；缺失附件会明确告知不能猜测内容。
- 全局面板可选择是否引用唤起时的屏幕，附带缩略图，支持文本和按住说话。发送后沿用当前会话，完成后返回原应用并显示可关闭的结果浮层，点结果可查看对话。快照被明确标记为历史画面。原草稿会在全局任务结束后恢复，忙碌期间收到的全局请求排队。
- 悬浮窗口的创建、显示和移除统一在主线程执行；读取屏幕时暂时隐藏助手结果，避免把自己的结果浮层送入下一次截图。

聊天输入栏的微信式录音布局、持续按压手势以及松手取消规则沿用已有实现。本次没有更换配色基准。

## 语音服务的实际阻碍

已按用户授权读取 Text.txt 并验证 Key，没有将 Key 写入仓库或验收截图。真实火山服务返回 HTTP 403：`requested resource not granted`。当前 Key 无权使用 `volc.seedasr.sauc.duration`；测试另外两个资源也被拒绝。设置页的连接检查显示同样原因，证据为 `speech-check.png`。

需要在豆包语音控制台确认 Key 所属项目及 Seed ASR 2.0 小时版授权，或换用具备授权的语音 Key。接口依据为[官方双向流式识别文档](https://docs.volcengine.com/docs/DoubaoVoice/bidirectional-streaming-automatic-speech-recognition-websocket?lang=zh)，并与 ../doubao-say 的接入方式对齐。

手机已保存火山语音 Key，未配置 Deepgram Key（只读取配置是否存在，不导出 Key）。**本次完整语音转写、持续录音手势和语音发起任务尚未验收通过。** 未用模拟服务替代真实语音结果，也未把历史成功截图当成本次成功证据。

## 真机链路

设备为 Xiaomi M2006J10C，MIUI 14，1080 × 2400；APK 覆盖安装，使用设备锁和 Midscene 操作。运行时状态通过专用调试通道只读核验，UI 操作由 Midscene 完成。

1. Android 文档选择器选中自建 `tapilot-e2e-note.txt`，打开预览后可见项目“松果”和编号“TP-1047”。发送问题，模型真实回复 `TP-1047`。
2. 点“复制”，从系统键盘剪贴板粘贴，输入栏显示 `TP-1047`；键盘没有挡住发送区域。
3. 长按用户消息，选“编辑后重发”，原文字和附件恢复到输入栏。修改问题并发送，真实回复“松果”。
4. 重启应用，点击成功回复的“重新执行”，确认后仍回复“松果”；私有附件引用保持一致。
5. 发出长回复请求，点击“停止”，运行时记录为 `stopped`，没有设备执行报告。
6. 发送“打开手机的计算器，不用输入数字。”，确认后由应用中的 Midscene 打开计算器，真实成功记录生成 Agent 报告及 Runner 摘要，报告入口正常打开。
7. 从计算器唤起全局面板，切换屏幕引用开关，再勾选后发问。助手真实回复“计算器”，顶部标签为“计算”和“换算”。新消息与文件任务具有同一会话 ID；保存的截图可打开预览。
8. 返回聊天追问原文件编号，仍真实回复 `TP-1047`，验证跨应用后文件上下文保留。

最终 APK 中复测了取消屏幕引用：在“问 Tapilot”面板取消勾选后发送算术问题，真实回复 `4`，返回计算器并显示结果浮层。聊天页和面板使用独立的上下文槽，避免主页面恢复时提前消费面板截图。此前一次自动化在聊天页代替操作，未计为这个用例通过；最终复测明确操作了面板复选框。

测试过程中系统无障碍快捷按钮曾与助手悬浮球重叠，误触导致服务关闭；已通过系统 UI 保留服务开启并关闭快捷按钮。没有修改网络服务或系统代理。

本轮没有重新覆盖相机拍摄、PDF 全链路、横屏、平板、最大系统字体、Deepgram 实际转写和真实弱网。实际模型任务临时使用本机已有的可用模型。结束后恢复原凭据及 `custom / qwen3.5-plus` 配置，重启后只读核验确认恢复成功。本次未重新验证原模型 API 是否可用。测试用下载文件已删除，私有附件副本保留供历史预览；设备锁已释放。
