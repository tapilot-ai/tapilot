# 执行模式

设置 → 任务与记录 → 执行模式，提供三种选项：

- 自动执行（YOLO）：直接执行 Agent 发起的手机操作，不触发 Tapilot 的操作确认。
- 关键操作确认：发送、付款、删除等操作前确认。
- 每次操作确认：每次调用手机操作前确认。

旧版本的“每次操作前确认”开启时映射为每次操作确认，关闭时映射为关键操作确认。用户选择新模式后，新配置优先，并保存到原生会话存储，重启后保留。默认行为不变。

YOLO 控制应用自身的操作确认，不改变 Android 权限或身份验证。高级 YAML 仍使用原有直接执行流程。
