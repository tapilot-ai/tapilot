# 微信语音界面验证（2026-10-02）

> 历史记录：此文对应临时恢复为 WebView 的版本。该恢复错误撤回了原生聊天代码，现已修正；当前状态见 [代码恢复与配色核查](native-brand-repair-20261002.zh.md)。
## 参考与实现

以用户提供的微信截图 `1790940116854_6ef0e928251d5ed1.png` 为视觉参考，替换旧蓝紫色录音卡片：全屏暗色遮罩、绿色波形气泡、松手提示、左右滑动区域、底部灰色弧面。遮罩覆盖应用标题栏。波形为录音状态动画，尚未接入实时音量。

当前聊天界面使用恢复后的 WebView / HTML / CSS / TypeScript；Kotlin 原生迁移保存在备份分支。

## 手势

- 长按文本框进入录音，正常松手转写到草稿。
- 语音模式正常松手将转写文本发送给助手。
- 向上滑动进入取消候选，松手才取消；移回输入区继续录音。
- 向右上滑动进入转文字候选，松手将文本放入草稿。

## 验证结果

类型检查通过；18 个测试文件、64 个测试通过，其中 3 个测试覆盖手势分类、移回恢复和右侧转文字。前端和 Android Debug APK 构建通过，覆盖安装到小米 M2006J10C / MIUI 14，未清除应用数据。

真机连续触摸验证了正常录音、上滑取消候选、右侧转文字候选、移回继续录音及最终松手取消；取消后录音浮层消失，输入框恢复，没有新增消息。本轮验证范围为界面和录音手势，未验证右侧松手后的实际转写，也未执行模型任务。
