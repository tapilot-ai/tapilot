# 开启后台屏幕（实验性）

此功能仅在 Debug 版本中提供，默认关闭。开启“用于聊天任务”后，普通聊天中的手机操作会在独立屏幕执行，并显示悬浮预览。应用兼容性因设备而异；Beta 和 Release 不包含此功能。

## 首次设置

需要 Android 12 或更高版本，建议 Android 14 及以上。设置期间连接 Wi-Fi，全程无需电脑或 USB 线。

1. 打开 **设置 → 后台屏幕（实验性）**。
2. 开启“用于聊天任务”，阅读 Shell 辅助说明，点击 **同意并设置**。如果希望重启后也自动恢复连接，可以勾选 **自动恢复连接**；这一选项默认关闭，会说明所需权限。
3. 按提示开启开发者选项、USB 调试和无线调试。USB 调试用于自动恢复，无需接线。已经开启的开发者选项会跳过；如果手机无法正确报告状态，可以点 **已完成** 继续。
4. 允许 Tapilot 的配对通知。在系统无线调试页面点击 **使用配对码配对设备**，保持弹窗打开。
5. 下拉通知栏，在 Tapilot 通知中点击 **输入配对码**，填写六位数字并提交。配对完成前不要切换应用或关闭系统弹窗。
6. Tapilot 会自动查找端口并连接。点击通知回到应用，授予悬浮窗权限后，看到辅助已连接即可返回聊天，发送包含应用名称的任务。
7. 可选：在“高级选项”中打开“试用后台屏幕”，试用会打开内置测试页。点击 **允许悬浮预览** 并在系统中授权后返回，点击悬浮屏内的测试按钮，确认页面显示“屏幕测试通过”。试用不会打开个人应用。

正常流程不需要分屏，也不用填写 IP 地址或端口。辅助连接成功不代表所有应用都兼容虚拟屏；操作失败时不会转到主屏执行。

## 聊天任务与接管

任务开始时确定使用主屏还是后台屏幕，执行中不会自动切换。纯文字问答不会创建副屏。请在任务中说明应用名称；应用启动、截图、点击、滑动和支持的按键均定向到本次副屏。不支持的系统级操作会明确失败。

中文等文字通过副屏中已聚焦的可编辑无障碍节点输入，不读取主屏输入框；缺少此能力时会报错。虚拟屏按当前手机的分辨率、比例和密度创建，每边最多 2560 像素、总计约四百万像素，必要时同比缩放密度。悬浮窗只缩小展示画面，不改变应用布局。

点击任务中的“接管”，等待运行和在途输入停止后，可操作悬浮屏。明确点击“继续”后，模型重新观察手动操作后的状态。任务完成、普通停止、关闭悬浮窗、断连或关闭设置开关都会释放副屏；接管时保留画面供你操作。关闭后台屏幕保留配对，新任务使用主屏，正在运行的任务不会迁移到主屏。恢复连接不会重建任务。

## 以后如何使用

Tapilot 会保留配对身份和你的授权选择。关闭设置页不会撤销授权，退出测试页会释放测试屏幕。

无线调试仍然开启时，Tapilot 会尝试自动重连。开启“自动恢复连接”后，会通过已配对的 Shell 授予本 Debug 应用 Android 安全设置写入权限，用于在连接 Wi-Fi 且 USB 调试开启时请求重新开启无线调试，包括系统重启后。新的 Wi-Fi 网络仍可能需要你在系统中批准；部分手机的后台限制、强行停止或权限拒绝可能要求手动恢复。

自动恢复不会切换 Wi-Fi、开启无障碍、重新创建虚拟屏或继续中断的任务。关闭自动恢复或撤销授权后，不再修改系统开关。Android 已授予的设置权限可能仍保留，但 Tapilot 不再使用它。

## 停止与撤销

- **停止并释放**：关闭当前虚拟屏，保留辅助授权。
- **撤销 Shell 辅助授权**：在设置页或常驻通知中操作，立即停止辅助和虚拟屏，并关闭自动恢复。
- **清除配对**：撤销授权并删除本地密钥；请同时在系统无线调试的已配对设备中移除 **Tapilot**。

## 遇到问题

收不到通知时，检查 Tapilot 通知权限和“手机配对”通知类别是否开启；没有顶部横幅时，也可以下拉通知栏。

配对码过期时，重新打开系统配对弹窗，输入新验证码即可。验证码不会保存。

自动发现失败时，展开 **高级选项**，按提示将 Tapilot 与系统设置分屏，再填写配对端口和验证码。配对成功后若仍不能连接，填写无线调试主页中的连接端口。两个端口不同。

如果自动恢复权限被系统拒绝，手动开启无线调试后重试，不必立即清除已有配对。手机没有无线调试入口时，当前手机内设置流程不可用；开发者可使用电脑启动脚本进行诊断。

## 已验证的设备差异

Android 15 模拟器已验证自动恢复和重启后恢复连接。OPPO Find N（Android 14）已验证通知栏配对、Shell 连接和悬浮屏点击，但系统拒绝授予自动恢复所需的安全设置权限；这台设备需要手动重新开启无线调试。勾选自动恢复不代表权限已经生效，请以页面状态为准。重新连接不会创建屏幕或继续任务。

## 让 Agent 完成测试页任务

连接 Shell 辅助并允许悬浮预览后，选择“让 Agent 试用独立屏幕”。这是单独确认的模型任务：将内置测试屏截图和计数目标发送给 Tapilot 当前配置的模型，调用可能产生费用；报告保存在应用内。此试用独立于普通聊天任务，位于“高级选项”。

目标是让测试计数增加一次。Midscene 执行操作并进行视觉断言，同时核对实际计数；只支持测试副屏上的点击和滑动，不支持的动作会报错，不会转到主屏。

先点“暂停并接管”，等页面显示由你操作后，再操作悬浮屏。继续时重新观察，目标不变；手动操作已经达到目标时，应仅验证，不再点击。关闭悬浮窗、销毁试用页面、撤销授权、断连或超过三分钟都会停止任务；重连和屏幕旋转不会自动重跑。

当前仍为 Debug 实验，不能保证所有应用、受保护页面或熄屏场景可用。详见[验证记录](../../tests/verification/virtual-agent-2026-11-03.md)。
