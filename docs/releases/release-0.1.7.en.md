# Tapilot 0.1.7 Beta

- Hold the floating assistant to speak without opening the main chat screen.
- See live transcripts before a task starts. Release to send, or slide to Cancel and release to discard.
- Voice controls follow Vibelet styling; the transcript bubble keeps the app accent color when cancellation is selected.
- Keep spoken text visible during processing and after spoken replies. Pause, resume, interrupt, or end a conversation from the overlay.
- Start microphone capture earlier to retain opening words.
- Recover from interrupted model connections with one bounded retry of the same model request, without replaying phone operations.

Android 11+ · ARM64 · Beta. Uses the existing development signing certificate.
