# Tapilot 0.1.5 Beta

Maintenance release with a new Android version identifier and completed voice-task verification.

- Verified real microphone input with Volcengine Seed ASR 2.0.
- Verified sending the recognized instruction to Pi Agent and completing a calculator task through Midscene, including a final screen assertion.
- Includes the same application features as 0.1.4. Configure your own speech API key in Settings; credentials are not included in the APK.

Android 11+, ARM64. This beta uses the existing debug signing certificate.
