# 语音对话继续行为回归（2026-10-20）

## 问题与修复

OPPO 现场截图中，悬浮语音页已经显示用户说的话，状态却为“语音已暂停”；对话历史仍停在助手追问，没有保存该回答。旧“继续”调用 `resume()`，重新开始录音并清空当前转写，不会把可见回答提交给对话。这解释了“已经回答，再点继续仍在录音”的体验。

- 将“继续对话”与“重新录音”分开；有未提交的转写时提交该回答，否则发送当前语言的“继续”，沿用现有对话。
- 录音中点击继续必须先结束录音并等待最终识别，不能因为尚未收到中间转写就丢掉已采集的音频。只有最终识别为空时才发送“继续”；网络与服务错误仍显示错误，不冒充空语音。
- 用 `transcriptPending` 区分未发送转写和上次已提交内容，避免重放旧回答。30 秒收听上限保持不变，超时不自动提交不完整内容；用户明确点击后可提交仍可见的转写。
- 等待当前任务期间不重复提交或重新开启麦克风；“继续对话”不能替代手机操作确认。
- 迟到的麦克风就绪回调不能覆盖正在转写的状态。
- 主对话页、悬浮语音页和通知使用一致的继续语义，中英文按钮同步；主页面按钮支持换行。
