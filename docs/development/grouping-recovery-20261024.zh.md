# OPPO 图标分组恢复记录

## 现场问题

手机同时安装了主应用 `lifeos.md.tapilot` 和旧登录验证包 `lifeos.md.tapilot.siwcverify`，两者都显示 Tapilot。主应用最后更新时间为 2026-10-23，验证包为 2026-10-14。主应用的设备控制服务出现在系统 crashed 列表，验证包的同名服务仍绑定，容易从悬浮球进入旧应用。

最初打开主应用里的历史报告，不是用户联网后在验证包里运行的最新任务。联网后的旧包任务 `4d2efcd3-0d81-470a-a442-33f434831acb` 确实完成了模型定位并多次调用 DragAndDrop，但没有建成文件夹；独立 LongPress 弹出了快捷菜单。后续任务 `9c91a7a6-c5f8-44d9-a56a-00505c610859` 又拍到另一应用的错误页。不能把这些记录统一解释为断网。

主应用的连接检查另行确认了 ChatGPT 授权失效。已重新走浏览器授权，成功加载模型目录；后续真实模型请求返回 HTTP 200。没有复制测试包的令牌或清空应用数据。

## 处理

停用旧验证包并保留数据，覆盖安装新版主应用。安装后主应用的设备控制服务重新绑定，已不在 crashed 列表。今后通过 speechVerification、e2eVerification 构建的测试包，应用和辅助功能服务名称分别带 Speech Test、E2E Test，避免同名入口。

新版连续拖拽实际创建了 Tools 文件夹，内含 LynxExplorer 和 Flutter Gallery。但独立核验对正确截图返回了错误观察，把文件夹内部图标判断为桌面独立图标，并要求截图证明其他图标此前没有变化，导致对话层重复操作。已保留当时报告与核验图片，未把负面结果改成成功。

本轮精简重复核验提示，只保留一次目标与范围说明，明确按当前视图、标题和视觉层级读取，区分可见结果与操作历史约束。没有添加应用名称、坐标、桌面图标或文件夹专用识别规则；有效的负面判断仍直接返回，不通过反复请求把它刷成成功。
